## 🌐 Free 2-Minute Deployment Options

### Option A: GitHub Pages (Recommended)
1. Push this `portfolio` folder to a new public GitHub repository named `portfolio` or `varun-st-portfolio`.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root` (or `/portfolio`), then click **Save**.
4. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`.

### Option B: Vercel (Instant HTTPS)
1. Go to [vercel.com](https://vercel.com).
2. Click **Add New Project** and import your GitHub repo.
3. Click **Deploy**. Done in 30 seconds with a free `.vercel.app` domain.
